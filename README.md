# ⚽🏀🥎🏈 Marcador Deportivo

### Contabiliza los puntos en un marcador

Solución tecnológica diseñada para la gestión de la puntuación de dos equipos, su incremento, decremento y reseteo del marcador.

---

## 🛠️ Stack tecnológico

Este proyecto se desarrolla utilizando las siguientes tecnologías:

* **Dart** - v3.13.7
* **Flutter** - v3.47.9
